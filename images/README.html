图片目录说明

这个目录用于存放博客中使用的所有图片，包括：

目录结构

照片命名规范

  • 使用英文或拼音命名
  • 文件名应具有描述性
  • 建议格式：分类-描述-日期.jpg
  • 示例：landscape-sunrise-20240115.jpg

图片规格建议

  • 头像图片：建议 200x200px 或 400x400px，正方形
  • 照片分享图片：建议宽度 800-1200px，保持比例
  • 横幅图片：建议宽度 1200-2000px，高度 300-500px

添加照片步骤

  1. 将照片放入对应的分类目录
  2. 在 source/_data/photos.yml 中添加照片信息
  3. 更新照片的 image 字段为正确的路径
  4. 重新生成博客查看效果

支持的图片格式

  • JPEG (.jpg, .jpeg) - 推荐用于照片
  • PNG (.png) - 推荐用于图标和透明图片
  • GIF (.gif) - 动态图片
  • WebP (.webp) - 现代格式，文件更小

优化建议

  • 使用图片压缩工具减小文件大小
  • 保持图片质量的同时优化加载速度
  • 为重要图片添加alt文本描述
