1. 计算机系统基础

1.1 计算机启动过程

计算机启动过程：

  1. CPU加电，CS:IP指向FFFF0H - CPU开始执行
  2. 执行BIOS中的JMP跳转指令 - 跳转到BIOS启动代码
  3. 硬件自检 - POST(上电自检)检测硬件
  4. 登记BIOS中断程序入口地址 - 建立中断向量表
  5. 操作系统引导 - 加载操作系统

正确的执行顺序：1 → 2 → 3 → 4 → 5

关键知识点：

  • BIOS位于ROM中，地址FFFF0H
  • BIOS执行JMP指令跳转到启动代码
  • POST检测内存、显卡、键盘等设备
  • 建立中断向量表后，操作系统才能正常响应中断
  • 最后加载操作系统引导程序到内存

1.2 操作系统的特征

  • 并发性：多个程序同时运行
  • 共享性：系统资源被多个进程共享
  • 虚拟性：将物理资源虚拟为逻辑资源
  • 异步性：进程执行的不确定性

1.3 操作系统的基本功能

  • 进程管理：进程的创建、撤销、调度、同步、通信
  • 存储管理：内存分配、回收、保护、扩充
  • 文件管理：文件的创建、删除、读写、保护
  • 设备管理：设备的分配、回收、驱动、控制

2. 进程管理

2.1 进程基础概念

2.1.1 进程的定义

进程是程序的一次执行过程，是操作系统进行资源分配和调度的基本单位。

2.1.2 进程控制块(PCB)

进程控制块包含：

  • 进程标识信息：PID、父进程PID
  • 进程状态信息：就绪、运行、阻塞
  • 进程调度信息：优先级、调度算法信息
  • 进程资源信息：内存地址、文件描述符、I/O设备
  • 进程上下文信息：寄存器值、程序计数器

2.1.3 进程状态转换

进程状态：

  • 就绪态：进程已获得除CPU外的所有资源，等待调度
  • 运行态：进程正在CPU上执行
  • 阻塞态：进程等待某事件（如I/O完成）而暂停执行

状态转换：

  • 就绪 → 运行：进程被调度选中
  • 运行 → 就绪：时间片用完或被高优先级进程抢占
  • 运行 → 阻塞：进程请求I/O或等待某事件
  • 阻塞 → 就绪：等待的事件发生

2.2 进程并发与并行

2.2.1 并发

并发是指多个进程在同一个处理器上交替执行，看起来同时运行。

特点：

  • 单处理器系统
  • 进程间时间片轮转
  • 宏观上同时执行，微观上交替执行

2.2.2 并行

并行是指多个进程在多个处理器上真正同时执行。

特点：

  • 多处理器系统
  • 真正的同时执行
  • 不存在时间片轮转

2.3 进程调度

2.3.1 调度类型

  • 高级调度：作业调度，从外存后备队列选择作业创建进程
  • 中级调度：内存调度，进程在内存与外存间交换
  • 低级调度：进程调度，从就绪队列选择进程执行

2.3.2 调度算法

  • 先来先服务(FCFS)：按到达时间顺序
  • 短作业优先(SJF)：选择估计运行时间最短的作业
  • 时间片轮转(RR)：每个进程分配固定时间片
  • 优先级调度：按优先级高低调度
  • 多级反馈队列：结合多种调度算法

2.3.3 调度相关问题

降低进程优先级的合理时机：

  • 进程的时间片用完
  • 进程长期处于就绪队列中

错误选项分析：

  • B选项错误：时间片用完后进程转为就绪态，不是阻塞态

3. 存储管理

3.1 分区存储管理

3.1.1 分区类型

  • 固定分区：分区大小固定不变
  • 动态分区：分区大小根据需要动态分配
  • 可重定位分区：支持紧凑技术

3.1.2 碎片问题

  • 内部碎片：分配给进程的内存空间大于实际需求的部分
  • 外部碎片：内存中存在的无法使用的小块空闲内存

区别：

  • 内部碎片：进程内部，浪费的是进程的内存空间
  • 外部碎片：进程之间，浪费的是系统总的空闲内存

3.2 分页存储管理

3.2.1 分页基本概念

  • 页面：将逻辑地址空间分成大小相等的页
  • 页框：将物理内存分成大小相等的块
  • 页表：记录页面与页框的对应关系

3.2.2 地址转换

地址转换过程：

  1. 分离页号和页内偏移量
  2. 通过页表查找对应的页框号
  3. 物理地址 = 页框号 × 页面大小 + 页内偏移量

3.2.3 二级页表

结构：

优势：

  • 减少页表占用的内存空间
  • 支持更大的地址空间
  • 按需分配页表

3.3 分段存储管理

3.3.1 分段概念

分段特点：

  • 按程序逻辑结构划分
  • 每个段有独立的名字和长度
  • 段长不固定
  • 段间可独立保护和共享

3.3.2 段表结构

逻辑地址格式：

转换过程：

  2. 通过段表查找段基址
  3. 检查偏移量是否超过段长
  4. 物理地址 = 段基址 + 段内偏移量

3.4 段页式存储管理

3.4.1 地址结构

3.4.2 转换过程

  1. 分离段号、页号和页内偏移量

4. 虚拟存储

4.1 虚拟存储基本概念

4.1.1 定义

虚拟存储是指将部分外存空间作为内存的扩展，实现程序运行超过实际内存容量的技术。

4.1.2 原理

  • 局部性原理：程序执行表现出局部性特征
  • 页面置换：将不常用的页面换出到外存
  • 按需调页：运行时才调入需要的页面

4.2 页面置换算法

4.2.1 置换算法类型

  • OPT(最优置换)：置换将来最长时间不使用的页面
  • FIFO(先进先出)：置换最先进入内存的页面
  • LRU(最近最少使用)：置换最近最少使用的页面
  • Clock(时钟算法)：LRU的近似实现
  • LFU(最不常用)：置换访问次数最少的页面

4.2.2 算法特点

  • OPT：理论最优，但无法实现
  • FIFO：简单但可能产生Belady异常
  • LRU：效果好但实现成本高
  • Clock：LRU的有效近似

5. 中断与系统调用

5.1 中断机制

5.1.1 中断类型

  • 外部中断：来自CPU外部的中断
    • 硬件中断：I/O设备、时钟等
    • 外部中断：电源故障、硬件错误
  • 内部中断：来自CPU内部的中断
    • 程序中断：除以零、越界等
    • 陷阱：系统调用、调试断点

5.1.2 中断向量表

适合的数据结构：

  • 数组：随机访问效率高
  • 哈希表：快速查找
  • 链表：灵活但访问慢

中断向量表作用：

  • 存储中断服务程序的入口地址
  • 提供中断处理的入口点

5.1.3 中断处理过程

  1. 中断请求：设备向CPU发送中断请求
  2. 中断响应：CPU保存现场，识别中断源
  3. 中断处理：执行中断服务程序
  4. 中断返回：恢复现场，返回原程序

5.2 系统调用

5.2.1 系统调用概念

系统调用是操作系统为应用程序提供的服务接口，是用户程序与操作系统交互的桥梁。

5.2.2 系统调用特点

  • 正确选项分析：
    • I错误：执行系统调用时CPU处于内核态，但系统调用完成后回到用户态
    • II正确：避免用户程序直接访问外设，提高系统安全性
    • III错误：不同操作系统的系统调用接口不统一
    • IV正确：系统调用是内核为应用提供的服务接口

5.3 键盘输入的完整过程

进程从键盘输入字符的过程：

  1. 用户在键盘上输入字符
  2. 将字符从键盘控制器读入系统缓冲区
  3. 启动键盘中断处理程序
  4. 将进程P插入阻塞队列
  5. 将进程P插入就绪队列
  6. 进程P从系统调用返回

6. 同步与互斥

6.1 基本概念

6.1.1 临界区与临界资源

  • 临界区：进程中访问临界资源的代码段
  • 临界资源：一次只能被一个进程使用的共享资源

6.1.2 同步与互斥条件

互斥条件：

  • 互斥使用：资源不能同时被多个进程使用
  • 请求与保持：进程请求新资源时不释放已占有资源
  • 非抢占：资源不能被强制夺走
  • 循环等待：进程间形成等待资源的环形链

6.2 信号量机制

6.2.1 信号量类型

  • 整型信号量：信号量值为整数
  • 记录型信号量：包含等待队列的信号量
  • 二值信号量：值为0或1的信号量

6.2.2 P、V操作

  • P操作(Wait)：申请资源，信号量减1
  • V操作(Signal)：释放资源，信号量加1

6.2.3 生产者-消费者问题

问题描述：

  • P1：生产者，生产产品送到工作台
  • P2：消费者，取走合格产品
  • P3：消费者，取走不合格产品
  • 工作台：能放N个产品的缓冲区

6.3.1 经典同步问题

  • 生产者-消费者问题

  • 哲学家就餐问题

  • Monitor：面向对象的同步机制

7. 死锁

7.1 死锁基本概念

7.1.1 死锁定义

死锁是指两个或多个进程在执行过程中，因争夺资源而造成的一种互相等待的现象。

7.1.2 死锁产生的必要条件

  1. 互斥条件：资源一次只能被一个进程使用
  2. 请求与保持条件：进程保持已获得的资源并请求新资源
  3. 非抢占条件：进程已获得的资源不能被抢占
  4. 循环等待条件：存在进程资源的环形等待链

7.2 死锁预防

7.2.1 预防策略

  • 破坏互斥条件：共享资源无法破坏
  • 破坏请求与保持：进程一次性申请所有资源
  • 破坏非抢占条件：允许抢占资源
  • 破坏循环等待：按固定顺序申请资源

7.3 死锁避免

7.3.1 银行家算法

算法思想：

  • 预分配资源时检查系统是否安全
  • 系统处于安全状态时才分配资源

7.3.2 安全状态判断

算法步骤：

  1. 找到满足条件的进程
  2. 模拟分配资源并完成进程
  3. 重复步骤1，直到所有进程完成或无法继续

8. 设备管理

8.1 I/O控制方式

8.1.1 控制方式类型

  • 程序直接控制方式：CPU轮询控制
  • 中断驱动方式：中断方式控制
  • DMA方式：直接内存访问
  • 通道方式：专门的I/O处理器

8.1.2 中断驱动I/O

特点：

  • CPU启动I/O后可以处理其他任务
  • I/O完成后通过中断通知CPU
  • 提高了CPU利用率

8.2 磁盘调度

8.2.1 调度算法类型

  • 先来先服务(FCFS)：按请求顺序服务
  • 最短寻道时间优先(SSTF)：选择距离当前磁头最近的请求
  • 扫描算法(SCAN)：磁头沿一个方向移动，遇到边缘后反向
  • 循环扫描(CSCAN)：磁头沿一个方向移动，到达边缘后快速返回起点

8.2.2 CSCAN算法计算

题目条件：

  • 磁道数：400 (0~399)
  • 当前磁头位置：200号磁道
  • 移动方向：向外(磁道号增加)
  • 请求：300, 120, 110, 0, 160, 210, 399

计算步骤：

  1. 当前磁头位置：200
  2. 移动方向：向外(磁道号增加)
  3. 按方向排序请求：210, 300, 399, 160, 120, 110, 0
  4. 磁头移动路径：200→210→300→399→0→110→120→160
  5. 移动距离详细计算：
    • 200→210: 10
    • 210→300: 90
    • 300→399: 99
    • 399→0: 399 (快速返回)
    • 0→110: 110
    • 110→120: 10
    • 120→160: 40
    • 总距离: 10+90+99+399+110+10+40 = 758

9. 文件系统

9.1 文件系统基本概念

9.1.1 文件组织结构

  • 无结构文件：字节流
  • 记录式文件：记录序列
  • 索引式文件：带有索引的文件

9.1.2 目录结构

  • 一级目录：所有文件在同一目录
  • 二级目录：根目录下的用户目录
  • 树形目录：多级目录结构
  • 无环图目录：允许文件共享

9.2 文件分配方法

9.2.1 连续分配

  • 特点：文件占用连续的磁盘块
  • 优点：访问速度快，支持随机访问
  • 缺点：产生外部碎片，文件大小难以预测

9.2.2 链接分配

  • 隐式链接：文件分配表记录链接关系
  • 显式链接：文件分配表(FAT)集中管理
  • 优点：无外部碎片，文件大小可变
  • 缺点：只能顺序访问

9.2.3 索引分配

  • 单级索引：每个文件有一个索引块
  • 多级索引：索引块再指向其他索引块
  • 优点：支持随机访问，无外部碎片
  • 缺点：索引开销大

12. 复习重点与技巧

12.1 核心考点

  1. 进程管理：状态转换、调度算法、进程通信
  2. 存储管理：分页分段、地址转换、页面置换
  3. 文件系统：文件分配、目录管理、磁盘调度
  4. 设备管理：I/O控制、中断处理、DMA
  5. 同步互斥：信号量、死锁、同步问题

12.2 复习技巧

  1. 理解原理：不要死记硬背，理解概念本质
  2. 多做计算：通过练习掌握各种计算方法
  3. 总结归纳：整理相似概念的区别和联系
  4. 实例分析：通过具体例子理解抽象概念

12.3 考试策略

  1. 先易后难：先做简单题，后做复杂题
  2. 仔细审题：注意题目中的关键词和条件

13. 计算机启动过程详细说明

13.1 标准启动顺序

逻辑启动过程：

  1. CPU加电，CS:IP指向FFFF0H - 处理器开始执行
  2. 执行BIOS中的JMP跳转指令 - 跳转到BIOS启动程序
  3. 硬件自检(POST) - 检测系统硬件状态
  4. 登记BIOS中断程序入口地址 - 建立中断向量表
  5. 操作系统引导 - 加载并启动操作系统

13.2 启动过程的逻辑关系

为什么是这个顺序？

  1. CPU启动(1)：系统上电后，CPU必须从预设地址开始执行
  2. BIOS跳转(2)：CPU需要跳转到BIOS启动代码
  3. 硬件检测(3)：在加载OS前，必须确认硬件正常工作
  4. 中断设置(4)：硬件检测完成后，才能建立完整的中断处理机制
  5. OS加载(5)：所有准备工作完成后，才能安全加载操作系统

13.3 易错点提醒

常见错误理解：

  • ❌ 认为操作系统可以直接启动
  • ❌ 忽略BIOS硬件自检的重要性
  • ❌ 不清楚中断向量表的建立时机

正确理解：

  • ✅ BIOS是硬件与操作系统的桥梁
  • ✅ 硬件自检是启动的必要条件
  • ✅ 中断处理是操作系统正常运行的基础

13.4 考试答题要点

排序题解题技巧：

  1. 记住基本逻辑：CPU启动 → BIOS执行 → 硬件检测 → 中断设置 → OS加载
  2. 理解因果关系：前一步是后一步的前提条件
  3. 掌握关键术语：POST、中断向量表、BIOS引导

标准答案：1 → 2 → 3 → 4 → 5

14. 补充重要问题答案

14.1 键盘输入过程正确答案

题目：进程P通过执行系统调用从键盘接收一个字符的输入，已知此过程中与进程P相关的操作包括：①将进程P插入就绪队列；②将进程P插入阻塞队列；③将字符从键盘控制器读入系统缓冲区；④启动键盘中断处理程序；⑤进程P从系统调用返回；⑥用户在键盘上输入字符。

正确答案顺序：⑥ → ③ → ④ → ② → ① → ⑤

详细过程说明：

  1. ⑥用户在键盘上输入字符 - 用户物理操作
  2. ③将字符从键盘控制器读入系统缓冲区 - 硬件层面数据传输
  3. ④启动键盘中断处理程序 - 操作系统响应中断
  4. ②将进程P插入阻塞队列 - 进程因等待I/O而阻塞
  5. ①将进程P插入就绪队列 - I/O完成后，进程转为就绪态
  6. ⑤进程P从系统调用返回 - 进程从系统调用中返回，获得输入字符

14.2 中断操作的执行过程

中断执行的基本步骤：

  1. 中断请求 - 外部设备向CPU发送中断信号
  2. 中断响应 - CPU完成当前指令后响应中断
  3. 保存现场 - 保存程序计数器、寄存器状态
  4. 关中断 - 防止中断嵌套
  5. 识别中断源 - 确定中断产生的原因
  6. 执行中断服务程序 - 处理具体的I/O操作
  7. 恢复现场 - 恢复被保存的寄存器状态
  8. 开中断 - 允许新的中断
  9. 返回断点 - 恢复被中断程序的执行

14.3 进程切换时的页式存储管理操作

在支持页式存储管理的系统中，进程切换时操作系统要执行的操作：

  1. 保存当前进程的上下文信息

    • 保存程序计数器、寄存器值
    • 保存页表指针和进程状态信息

  2. 切换页表

    • 加载新进程的页表基址寄存器
    • 更新内存管理单元(MMU)

  3. 更新内存保护信息

    • 设置新进程的内存访问权限
    • 更新相关页表的访问位

  4. 恢复新进程的上下文

    • 恢复新进程的寄存器值
    • 恢复新进程的进程状态

14.4 高级调度和低级调度填空题答案

高级调度也称为 作业 调度，是从外存的后备队列中选择合适的作业创建进程；而低级调度也称为 进程 调度，是从内存中的 就绪 队列中根据调度算法选择合适的进程运行。

14.5 时间片调度相关问题

关于基于时间片的进程调度，错误的是：

  • 错误选项：B - 当前进程的时间片用完后，该进程状态由运行态变为阻塞态
  • **正确答案：**时间片用完后，进程转为就绪态，等待下次调度

其他正确选项：

  • A正确：时间片越短，切换次数越多，系统开销越大
  • C正确：时钟中断后，修改时间片剩余时间
  • D正确：时间片大小受响应时间、系统开销、进程数量影响

14.6 降低进程优先级的合理时机

降低进程优先级的合理时机：

  • A. 进程的时间片用完 - 防止进程独占CPU
  • C. 进程长期处于就绪队列中 - 防止饥饿现象

14.7 CPU利用率计算详解

单道程序环境：

  • CPU利用率 = 进程运行时间 / 总时间
  • 公式：CPU利用率 = T_process / T

多道程序可抢占环境：

  • 考虑进程同时运行的情况
  • CPU利用率 = 1 - (I/O等待时间比例)^进程数
  • 公式：CPU利用率 = 1 - (p^n)，其中p是进程I/O等待比例，n是进程数

14.8 操作系统内核数据结构

在操作系统内核中，中断向量表适合采用的数据结构：

  • 数组 - 随机访问效率高，查找速度快
  • 中断号固定，便于数组索引

A. 让权等待 B. 空闲让进 C. 忙则等待 D. 无限等待
答案: D
解析: 同步机制不遵循无限等待原则。

38. 原语是( )
A. 运行在用户态的过程 B. 操作系统的内核
C. 可中断的指令序列 D. 不可分割的指令序列
答案: D
解析: 原语是不可分割的原子操作。

39. 若系统中有4个进程共享3台打印机，采用信号量机制控制打印机的共享使用，则信号量的取值范围是( )
A. [-1,4] B. [-2,2] C. [-1,3] D. [-3,2]
答案: C
解析: 最小值 = 进程数 - 资源数 = 4-3 = -1，最大值 = 资源数 = 3。

40. 下列关于进程死锁的描述中，错误的是( )
A. 若每个进程只能同时申请或拥有一个资源，就不会发生死锁
B. 若多个进程可以无冲突共享访问所有资源，就不会发生死锁
C. 若所有进程的执行严格区分优先级，就不会发生死锁
D. 若进程资源请求之间不存在循环等待，就不会发生死锁
答案: C
解析: 严格区分优先级并不能防止死锁。

15.4 存储管理 (41-49题)

41. 一次分配所有资源的方法可以预防死锁的发生，它破坏死锁4个必要条件( )
A. 互斥 B. 占有并请求 C. 非剥夺 D. 循环等待
答案: B
解析: 一次分配所有资源破坏了占有并请求条件。

42. 系统产生死锁的可能原因是( )
A. 独占资源分配不当 B. 系统资源不足 C. 进程运行太快 D. CPU内核太多
答案: A
解析: 死锁主要由资源分配不当引起。

43. 下面关于存储管理的叙述中，正确的是( )
A. 存储保护的目的是限制内存的分配
B. 在内存为M、有N个用户的分时系统中，每个用户占用M/N的内存空间
C. 在虚拟内存系统中，只要磁盘空间无限大，作业就能拥有任意大的编址空间
D. 实现虚拟内存管理必须有相应硬件的支持
答案: D
解析: 虚拟内存需要硬件支持（如MMU）。

44. 下列关于存储管理目标的说法中，错误的是( )
A. 为进程分配内存空间 B. 回收被进程释放的内存空间
C. 提高内存的利用率 D. 提高内存的物理存取速度
答案: D
解析: 存储管理不能提高物理存取速度。

45. 内存保护需要由( )完成，以保证进程空间不被非法访问。
A. 操作系统
B. 硬件机构
C. 操作系统和硬件机构合作
D. 操作系统或者硬件机构独立完成
答案: C
解析: 内存保护需要操作系统和硬件机构合作完成。

46. 设内存的分配情况如下图所示。若要申请一块40KB的内存空间，采用最佳适应算法，则所得到的分区首址为( )
[图形题，需要具体内存分配图]
A. 100K B. 190K C. 330K D. 410K
答案: C
解析: 最佳适应算法选择与请求大小最接近的空闲分区。

47. 动态重定位是在作业的( )中进行的。
A. 编译过程 B. 装入过程 C. 链接过程 D. 执行过程
答案: D
解析: 动态重定位在执行过程中进行。

48. 下列关于分页和分段的描述中，正确的是( )
A. 分段是信息的逻辑单位，段长由系统决定
B. 引入分段的主要目的是实现离散分配并提高内存利用率
C. 分页是信息的物理单位，页长由用户决定
D. 页面在物理内存中只能从页面大小的整数倍地址开始存放
答案: A
解析: 分段是逻辑单位，段长由逻辑结构决定。

49. 下列关于段式存储管理的叙述中，错误的是( )
A. 段是逻辑结构上相对独立的程序块，因此段是可变长的
B. 按程序中实际的段来分配主存，所以分配后的存储块是可变长的
C. 每个段表项必须记录对应段在主存的起始位置和段的长度
D. 分段方式对低级语言程序员和编译器来说是透明的
答案: D
解析: 分段对程序员是透明的，不需要考虑物理实现。

15.5 文件系统 (50-55题)

50. 文件系统在创建一个文件时，为它建立一个( )
A. 文件目录项 B. 目录文件 C. 逻辑结构 D. 逻辑空间
答案: A
解析: 创建文件时建立文件目录项。

51. 打开文件操作的主要工作是( )
A. 把指定文件的目录项复制到内存指定的区域
B. 把指定文件复制到内存指定的区域
C. 在指定文件所在的存储介质上找到指定文件的目录项
D. 在内存寻找指定的文件
答案: A
解析: 打开文件将目录项复制到内存。

52. 某用户程序发起open()系统调用，下列对该过程的描述中最准确的是( )
A. open()调用必然导致文件I/O
B. open()调用的参数含有需要打开的文件的文件名
C. open()调用完成后，系统打开文件表将增加一个表目
D. open()调用的参数的文件名不同时，必然会打开不同的文件实体
答案: B
解析: open()参数必须包含文件名。

53. 关闭文件操作的主要工作是( )
A. 将文件的最新信息从内存写回磁盘 B. 将文件当前的控制信息从内存写回磁盘
C. 将位示图从内存写回磁盘 D. 将超级块当前的信息从内存写回磁盘
答案: B
解析: 关闭文件主要写回控制信息。

54. 读文件操作的正确次序应该是( )
I. 向设备驱动程序发出I/O请求，完成数据交换工作
II. 按存取控制说明检查访问的合法性
Ⅲ. 根据目录项中该文件的逻辑和物理组织形式，将逻辑记录号转换成物理块号
IV. 按文件描述符在打开文件表中找到该文件的目录项
A. Ⅱ、Ⅳ、Ⅲ、Ⅰ
B. IV、II、III、I
C. IV、Ⅲ、II、I
D. II、IV、I、III
答案: A
解析: 读文件顺序：合法性检查→找到目录项→转换地址→执行I/O。

55. 目录文件存放的信息是( )
A. 某一文件存放的数据信息
B. 某一文件的文件目录
C. 该目录中所有数据文件目录
D. 该目录中所有子目录文件和数据文件的目录
答案: D
解析: 目录文件存放该目录下所有文件和子目录的目录项。

16. 高频考点总结

16.1 操作系统基础 (必考)

  • 基本特征: 并发、共享、虚拟、异步
  • 基本功能: 进程管理、存储管理、文件管理、设备管理
  • 用户接口: 命令接口、系统调用、图形接口
  • 系统类型: 批处理、分时、实时

16.2 进程管理 (重点)

  • 进程定义: 程序的一次执行过程
  • 进程状态: 就绪、运行、阻塞
  • 状态转换: 4种基本转换关系
  • PCB内容: 进程标识、状态、调度、资源、上下文信息
  • 进程同步: 临界区、临界资源、信号量机制
  • 死锁: 4个必要条件、预防和避免方法

16.3 存储管理 (重点)

  • 基本概念: 分区、分页、分段、段页式
  • 地址转换: 逻辑地址→物理地址的转换过程
  • 虚拟存储: 页面置换算法、请求分页
  • 存储保护: 操作系统与硬件机构合作

16.4 文件系统 (常考)

  • 文件操作: 创建、打开、读、写、关闭
  • 目录结构: 文件目录的组织和管理
  • 文件分配: 连续、链接、索引分配
  • 文件保护: 存取控制

16.5 考试技巧

  1. 概念理解: 深入理解基本概念，不要死记硬背
  2. 对比记忆: 相似概念要对比记忆
  3. 实例分析: 通过具体例子理解抽象概念
  4. 计算练习: 重点练习死锁计算、地址转换等计算题
