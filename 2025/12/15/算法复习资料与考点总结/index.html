1. 机器学习基础概念

1.1 机器学习分类

1.1.1 按任务类型分类

监督学习（Supervised Learning）

  • 定义：使用标注数据进行训练的学习方法
  • 任务类型：
    • 分类问题：预测离散值（如垃圾邮件检测、图像分类）
    • 回归问题：预测连续值（如房价预测、股票价格）
  • 特点：有明确的目标标签，模型学习输入与输出的映射关系

无监督学习（Unsupervised Learning）

  • 定义：使用未标注数据进行训练的学习方法
  • 任务类型：
    • 聚类问题：将相似数据分组（如客户分群、图像分割）
    • 降维问题：减少特征维度（如PCA、t-SNE）
    • 关联规则：发现数据项之间的关联关系
  • 特点：没有明确的目标标签，模型发现数据内在结构

半监督学习（Semi-supervised Learning）

  • 定义：结合少量标注数据和大量未标注数据的学习方法
  • 应用场景：标注数据稀缺但未标注数据丰富的场景

1.1.2 监督学习与无监督学习的主要区别

维度 监督学习 无监督学习
数据标注 有标注数据 无标注数据
学习目标 学习输入-输出映射关系 发现数据内在结构
评估方式 有明确的评估指标 评估相对困难
应用场景 预测和分类 发现模式和结构

1.2 分类与回归的区别

1.2.1 分类问题

  • 定义：预测离散值的任务
  • 输出：类别标签（如：垃圾邮件/正常邮件）
  • 评估指标：准确率、精确率、召回率、F1分数
  • 典型算法：逻辑回归、决策树、SVM、随机森林

1.2.2 回归问题

  • 定义：预测连续值的任务
  • 输出：数值（如：房价、股票价格）
  • 评估指标：均方误差(MSE)、平均绝对误差(MAE)、R²
  • 典型算法：线性回归、多项式回归、随机森林回归

1.2.3 区别总结

  • 输出类型：分类输出离散值，回归输出连续值
  • 目标函数：分类使用分类损失，回归使用回归损失
  • 应用领域：分类用于模式识别，回归用于数值预测

目标：寻找最优分类超平面，最大化分类间隔

常用核函数：

  • 高斯核（RBF）：K(x,y) = exp(-γ||x-y||²)

2.2 k近邻算法（k-NN）

2.2.1 算法过程

  1. 计算距离：计算待分类样本与训练集中每个样本的距离
  2. 选择邻居：选择距离最近的k个样本
  3. 投票决策：根据k个邻居的类别进行投票
  4. 返回结果：返回得票最多的类别（分类）或计算平均值（回归）

2.2.2 k值选择的影响

  • k值过小：
    • 容易导致过拟合
    • 对噪声数据敏感
    • 决策边界复杂
  • k值过大：
    • 容易导致欠拟合
    • 对噪声不敏感
    • 决策边界平滑

2.2.3 距离度量

  • 欧几里得距离：d(x,y) = √Σ(xᵢ-yᵢ)²
  • 曼哈顿距离：d(x,y) = Σ|xᵢ-yᵢ|
  • 余弦距离：d(x,y) = 1 - cos(θ)

2.3.2 决策树剪枝

预剪枝（Pre-pruning）

  • 定义：在决策树构建过程中进行剪枝
  • 方法：设置分裂阈值，如信息增益小于阈值则停止分裂
  • 优点：防止过拟合，节省训练时间
  • 缺点：可能欠拟合

后剪枝（Post-pruning）

  • 定义：先构建完整的决策树，然后进行剪枝
  • 方法：从叶节点向上剪枝，评估剪枝后的性能
  • 优点：通常性能更好
  • 缺点：训练时间长

4. 集成学习方法

4.1 集成学习基本概念

定义：通过结合多个学习器的预测结果来提高整体性能的方法

基本原理：

  • 偏差-方差权衡：通过结合多个模型减少总误差
  • 多样性：不同模型关注数据的不同方面
  • 投票机制：通过多数投票或加权平均得到最终结果

4.2 Bagging

原理：通过袋外样本和特征随机性减少方差

代表算法：随机森林

随机森林特点：

  • 使用多个决策树
  • 每个树使用不同的训练样本（Bootstrap采样）
  • 每个节点分裂时使用随机特征子集
  • 最终预测通过投票或平均得到

减少方差的原因：

  • 多个模型的预测平均
  • 减少个别模型的异常影响
  • 提高模型稳定性

4.3 Boosting

原理：通过迭代训练减少偏差

代表算法：AdaBoost、Gradient Boosting

AdaBoost算法步骤：

  1. 初始化样本权重
  2. 训练弱分类器
  3. 计算错误率和分类器权重
  4. 更新样本权重
  5. 重复步骤2-4

减少偏差的原因：

  • 关注之前分类错误的样本
  • 逐步改进模型性能
  • 组合多个弱分类器成为强分类器

4.4 Stacking

定义：堆叠多个模型的预测结果作为输入训练元学习器

结构：

  • 基层模型：多个基础学习器
  • 元学习器：使用基层模型输出作为输入

5. 深度学习基础

5.1 神经网络基本结构

5.1.1 激活函数

定义：神经网络中的非线性函数，引入非线性特性

主要激活函数：

1. Sigmoid函数

  • 公式：f(x) = 1/(1+e^(-x))
  • 范围：(0,1)
  • 特点：平滑，连续可微
  • 缺点：梯度消失，计算复杂

2. ReLU函数

  • 公式：f(x) = max(0, x)
  • 范围：[0,+∞)
  • 特点：计算简单，缓解梯度消失
  • 优点：广泛使用，效果好

3. Tanh函数

  • 公式：f(x) = (e^x - e^(-x))/(e^x + e^(-x))
  • 范围：(-1,1)
  • 特点：零中心化
  • 缺点：梯度消失

4. Softmax函数

  • 公式：f(xᵢ) = e^xᵢ/Σⱼe^xⱼ
  • 用途：多分类问题的输出层
  • 特点：输出概率分布

5.1.2 反向传播算法

定义：用于计算神经网络参数梯度的算法

算法步骤：

  1. 前向传播：计算网络输出
  2. 计算损失：计算预测值与真实值的差异
  3. 反向传播：从输出层向输入层传播梯度
  4. 参数更新：使用梯度下降更新参数

主要好处：

7. 模型评估与优化

7.1 过拟合与欠拟合

7.1.1 过拟合

定义：模型在训练数据上误差极低，但在未见过的数据上误差显著升高

产生原因：

  • 模型复杂度过高
  • 训练数据不足
  • 特征数量过多
  • 训练时间过长

解决方案：

  • 正则化：L1、L2正则化
  • Dropout：随机丢弃神经元
  • 交叉验证：评估泛化能力
  • 增加训练数据：提供更多样本

7.1.2 欠拟合

定义：模型在训练数据和测试数据上都表现不好

产生原因：

  • 模型复杂度过低
  • 特征数量不足
  • 训练不充分

解决方案：

  • 增加模型复杂度：使用更复杂的模型
  • 增加特征：提供更多有用特征
  • 减少正则化：适当减弱正则化强度

7.2 正则化技术

7.2.1 L1正则化

特点：产生稀疏权重向量

效果：

  • 自动进行特征选择
  • 产生稀疏解（很多权重为0）
  • 适用于特征选择场景

7.2.2 L2正则化

特点：所有参数都趋向较小值

效果：

  • 所有参数都被抑制
  • 防止参数过大
  • 提高模型稳定性

7.3 模型评估指标

7.3.1 混淆矩阵

结构：

含义：

  • TP（真正例）：实际为正，预测为正
  • TN（真负例）：实际为负，预测为负
  • FP（假正例）：实际为负，预测为正
  • FN（假负例）：实际为正，预测为负

7.3.2 精确率（Precision）

计算公式：TP/(TP+FP)

含义：预测为正的样本中实际为正的比例

7.3.3 召回率（Recall）

计算公式：TP/(TP+FN)

含义：实际为正的样本中被正确预测的比例

7.3.4 准确率（Accuracy）

计算公式：(TP+TN)/(TP+TN+FP+FN)

含义：正确预测的样本数除以总样本数

8.1 关联规则基本概念

8.1.1 关联规则定义

关联规则挖掘就是在交易数据库中挖掘强关联规则。

基本概念：

  • 事务：数据库中的一次交易或记录

  • 频繁项集：支持度大于等于最小支持度的项集
  • 关联规则：X → Y的蕴含式

8.1.2 频繁项集计算

基本步骤：

  1. 扫描数据库：计算每个1-项集的支持度
  2. 剪枝：删除支持度小于最小支持度的项集
  3. 连接：生成候选k-项集
  4. 计数：计算候选k-项集的支持度
  5. 重复：直到不能生成新的频繁项集

11. 算法填空题标准答案

11.1 机器学习基础填空

1. 机器学习按任务类型可分为 监督学习 、 无监督学习 和 强化学习 。

2. 若学习任务的目标是预测连续值，该任务称为 回归 。

3. 若学习任务的目标是预测离散值，该任务称为 分类 。

4. 在机器学习中，将数据集分为训练集、验证集和 测试 集，其中 测试 集用于最终评估模型的泛化能力。

11.2 算法相关填空

5. 线性回归中，最小化 均方误差 函数来估计参数。

6. 支持向量机中，使用 核 函数可以将数据映射到高维空间。

7. 支持向量机（SVM）中，核函数的作用是将低维空间中的 非线性可分 数据映射到高维空间。

8. 决策树算法C4.5使用 信息增益比 比率作为分裂标准。

9. ID3算法以信息论的 熵 为基础，以 信息增益 为”属性测试条件”。

10. 在神经网络中，使用 反向传播 算法来优化权重参数。

11.3 评估指标填空

11. 准确率是正确预测的样本数除以 总样本数 。

12. 逻辑回归使用 sigmoid 函数将输出映射到(0,1)区间。

11.4 正则化与采样

13. L2正则化在损失函数中添加参数的 平方和 。

14. 随机森林通过 自举 采样生成不同的训练子集。

11.5 深度学习相关

15. 卷积神经网络中的卷积核也称为 过滤器 。

16. 自然语言处理中， 词嵌入 表示将文本转换为数值向量的过程。

17. 主成分分析中，第一主成分是数据 方差 最大的方向。

11.6 其他重要概念

18. 贝叶斯分类器基于 贝叶斯 定理。

19. 集成学习通过结合多个 基础 模型来提高预测性能。

20. k-means聚类算法中，需要指定参数 k （聚类数量）。

11.7 数据预处理

21. 数据预处理中，将特征缩放到 [0,1] 区间的过程称为 归一化 （Normalization）。

22. 数据预处理中，标准化（Standardization）是将特征转换为均值为0、标准差为1的分布。

11.8 关联规则挖掘

23. 关联规则挖掘就是在 交易数据库 中挖掘强关联规则。

11.9 信息论基础

24. 组数据越有序，熵值越低；一组数据越无序，熵值越 高 。
