Qt QML 练习案例与进阶指南

发表于2025-11-10|更新于2025-11-10|Qt开发
|浏览量:

本文档包含多个Qt QML练习案例，从基础交互到高级特性，帮助开发者系统学习QML编程。案例涵盖UI设计、事件处理、属性绑定等核心概念，适合Qt初学者和进阶开发者参考。

代码功能说明

这个示例展示了一个简单的Qt QML应用程序，主要功能包括：

  1. 创建一个640x480的窗口
  2. 在窗口中央放置三个不同颜色的矩形（红色、蓝色、绿色）
  3. 为每个矩形添加点击事件，点击时会更新中间绿色矩形中的文本
  4. 使用了锚点布局、鼠标交互和属性绑定等QML核心概念

案例二：属性操作与Qt对象

下面的案例演示了如何操作窗口属性、使用Qt内置函数以及处理组件生命周期：

import QtQuick

Window {
    id:rootid
    width: 640
    height: 480
    visible: true
    title: qsTr("Hello World")

    property var fonts: Qt.fontFamilies()
    property string name: "Steve"
    
    onNameChanged: {
        console.log("Name:"+name)
    }
    onTitleChanged: {
        console.log("NEW tille:"+ title)
    }
    
    Text {
        anchors.centerIn: parent
        color: Qt.rgba(1,0,0,1)
        //md5加密哈希
        text: Qt.md5("text")
    }
    
    Rectangle{
        id:clickRectangele
        width: 300
        height: 100
        color: "dodgerblue"
        anchors.bottom: parent.bottom
    
        MouseArea{
            anchors.fill: parent
            onClicked: {
                rootid.name = "morry"
                rootid.title = "New title"
                // Qt.quit()
    
                // for(var i = 0 ; i < fonts.length ; i ++){
                //     console.log("["+i+"]",fonts[i])
                // }
    
                // Qt.openUrlExternally("https://pingju666.github.io/")
                // Qt.openUrlExternally("file://D:/个人文档/相片/105_PANA")
            }
        }
    }
    
    Component.onCompleted: {
        console.log("Name:"+name)
    }
}





这个案例展示了如何使用Qt QML中的属性系统、信号处理器以及一些实用的Qt全局函数。主要功能包括：

1. 获取系统字体列表
2. 属性变更时的信号处理
3. 使用Qt.md5()进行哈希计算
4. 窗口属性动态修改
5. 组件完成时的初始化操作

import QtQuick

Window {
    width: 640
    height: 480
    visible: true
    title: qsTr("Hello World")


    Rectangle{
        id:redid
        width: 50
        height: width * 1.5
        color: "red"
    }
    
    Rectangle{
        id:blueid
        color: "blue"
        width: 100
        height: 100
        //这个
        anchors.bottom: parent.bottom
        MouseArea{
            anchors.fill: parent
            onClicked: {
                redid.width = redid.width + 10
            }
        }
    }


    Rectangle{
        id:greenid
        color: "green"
        width: 100
        height: 100
        anchors.bottom: parent.bottom
        anchors.left: blueid.right
    
        MouseArea{
            anchors.fill: parent
            onClicked: {
                //破坏了绑定
                // redid.height = 100
                // redid.height = redid.width * 2.5
                //属性绑定
                redid.height = Qt.binding(function(){
                                              return redid.width * 2.5
                                          })
            }
        }
    }
}

这个案例重点演示了QML中的**属性绑定**机制：

1. **静态绑定**：通过表达式直接绑定（如`height: width * 1.5`）
2. **动态绑定**：使用`Qt.binding()`函数创建绑定
3. **绑定破坏与恢复**：展示了如何破坏和重新建立属性绑定

属性绑定是QML的核心特性，它允许UI元素的属性自动响应其他属性的变化，实现响应式界面。

## 学习要点总结

通过以上案例，我们可以掌握以下Qt QML核心概念：

1. **UI元素布局**：使用Row、anchors等实现灵活布局
2. **事件处理**：通过MouseArea捕获和处理用户交互
3. **属性系统**：声明属性、监听属性变化
4. **信号槽机制**：使用onXxxChanged处理属性变更信号
5. **属性绑定**：静态绑定和动态绑定的使用
6. **组件生命周期**：Component.onCompleted初始化
7. **Qt全局函数**：使用Qt命名空间中的实用函数

## 进阶学习建议

1. 尝试将多个小案例组合成一个完整应用
2. 学习使用QML的Model/View框架处理数据展示
3. 探索Qt Quick Controls提供的标准UI控件
4. 研究QML与C++交互的方法，扩展功能
5. 了解性能优化技巧，如视觉项缓存、渲染优化等

通过系统学习和实践这些概念，你将能够开发出功能强大、交互流畅的Qt QML应用程序。
