C语言基础概念

1.1 C语言的特点和优势

语言特性

  • 系统级语言：C语言直接操作内存和硬件，运行效率高
  • 结构化编程：支持函数分解，代码结构清晰
  • 可移植性：标准化程度高，移植性好
  • 库函数丰富：标准库提供大量实用函数
  • 指针操作：支持指针操作，提供强大的内存管理能力

应用领域

  • 操作系统开发（Linux、Windows内核）
  • 嵌入式系统开发
  • 数据库系统
  • 编译器开发
  • 高性能应用程序

1.2 程序的执行流程详解

四个编译阶段

  1. 预处理阶段：

    • 处理#include指令，插入头文件内容
    • 处理#define宏定义，文本替换
    • 处理条件编译指令（#ifdef、#ifndef）
    • 删除注释和多余空白字符

  2. 编译阶段：

    • 词法分析：将源代码分解为记号
    • 语法分析：检查语法结构，构建语法树
    • 语义分析：类型检查、符号表构建
    • 代码生成：将高级语言转换为汇编代码

  3. 汇编阶段：

    • 将汇编代码转换为机器指令
    • 生成目标文件（.obj或.o文件）
    • 地址重定位

  4. 链接阶段：

    • 解析外部符号引用
    • 将多个目标文件和库函数链接
    • 生成可执行文件

2.1 基本数据类型全面解析

整数类型详细说明

char类型（字符型）

  • 大小：1字节（8位）
  • 范围：-128 ~ 127（有符号） 或 0 ~ 255（无符号）
  • 用途：存储单个字符、ASCII码值、小整数
  • 声明方式：

short类型（短整型）

  • 大小：2字节（16位）
  • 范围：-32,768 ~ 32,767（有符号）或 0 ~ 65,535（无符号）
  • 用途：存储较小的整数，节省内存
  • 声明方式：

int类型（整型）

  • 大小：4字节（32位）
  • 范围：-2,147,483,648 ~ 2,147,483,647（有符号）
  • 用途：一般整数运算，默认选择
  • 声明方式：

long类型（长整型）

  • 大小：4或8字节（取决于平台）
  • 用途：存储大范围的整数
  • 声明方式：

long long类型（长长整型）

  • 大小：8字节（64位）
  • 范围：-9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807
  • 用途：存储超大整数

浮点类型详细说明

float类型（单精度浮点）

  • 大小：4字节（32位）
  • 精度：约7位十进制有效数字
  • 范围：约±3.4×10^(-38) ~ ±3.4×10^(38)
  • 用途：需要小数但精度要求不高的计算
  • 声明方式：

double类型（双精度浮点）

  • 大小：8字节（64位）
  • 精度：约15-16位十进制有效数字
  • 范围：约±1.7×10^(-308) ~ ±1.7×10^(308)
  • 用途：需要高精度的科学计算，默认浮点类型
  • 声明方式：

long double类型（扩展精度浮点）

  • 大小：通常16字节或更多
  • 精度：比double更高的精度
  • 用途：极高精度的科学计算

2.2 数据类型的选择原则

选择依据

  1. 数据范围：选择能容纳所有可能值的最小类型
  2. 精度要求：根据需要的精度选择合适类型
  3. 内存限制：在满足需求的前提下尽量节省内存
  4. 计算效率：不同类型可能有不同的计算效率

字符串复制函数详解

strcpy()函数：

功能：完整复制字符串（包含’\0’）

参数：

  • dest：目标字符串（必须足够大）
  • src：源字符串

返回值：返回dest的指针

注意事项：

  • 目标字符串必须有足够空间
  • 可能发生缓冲区溢出
  • 不检查空间大小

strncpy()函数：

功能：复制指定长度的字符串

参数n的含义：

  • 最多复制n个字符
  • 如果src长度小于n，会用’\0’填充剩余空间
  • 如果src长度大于等于n，不会添加’\0’

字符串连接函数详解

strcat()函数：

功能：将src连接到dest后面

原理：

  1. 找到dest的末尾（第一个’\0’位置）
  2. 在该位置复制src内容
  3. 在新结尾添加’\0’

注意事项：

  • dest必须有足够空间
  • src的’\0’会被复制，但dest原末尾的’\0’会被覆盖

calloc()函数详解

calloc()函数：

功能：分配并初始化为0的内存

参数：

  • n：元素个数
  • size：每个元素的大小

与malloc()的区别：

  • calloc()分配内存后自动初始化为0
  • malloc()分配的内存内容是随机的

realloc()函数详解

realloc()函数：

功能：调整已分配内存的大小

参数：

  • ptr：之前的内存指针
  • new_size：新的大小

返回值：返回调整后内存的指针

工作机制：

  • 如果可能，在原位置扩展内存
  • 如果不能，会分配新内存并复制内容
  • 如果new_size为0，相当于free()
