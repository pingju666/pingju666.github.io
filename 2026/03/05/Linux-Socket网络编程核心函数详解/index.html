Socket网络编程是Linux网络通信的基础，本文将详细介绍TCP服务器端和客户端编程中五大核心函数的使用。

一、socket() 函数 - 创建套接字

socket() 函数是Linux网络编程中用于创建套接字（Socket）的系统调用。套接字是网络通信的基础，几乎所有网络程序都要用到它。

函数原型

参数说明

参数 说明 常用值
domain 协议族 AF_INET（IPv4），AF_INET6（IPv6）
type 套接字类型 SOCK_STREAM（TCP），SOCK_DGRAM（UDP）
protocol 协议 0（自动选择）

返回值

  • 成功：返回一个非负整数，表示新创建的套接字描述符
  • 失败：返回 -1，并设置 errno 以指示错误原因

参数说明
